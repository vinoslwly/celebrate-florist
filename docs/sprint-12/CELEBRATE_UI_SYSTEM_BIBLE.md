## How to use this Bible

Read in order for onboarding. Prefer the linked phase documents over inventing new rules.

1. Start with **North Star** and **Visual DNA**.
2. Apply **Foundations** and **Surfaces** before components.
3. Use **Components**, **Themes**, and **Studio** rules for the surface you are building.
4. Check **Consistency** gaps and **QA** validation lists before implementing.
5. Append Founder decisions only via the **Decision Register**.

**Do not** invent a second visual language. **Do not** treat Production Pending as design failure. **Do not** implement without Founder clearance.

## Quick rules (do not skip the source docs)

| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Identity     | Landing is the visual baseline                                                                                                                  |
| Softness     | Controlled; glass selective                                                                                                                     |
| Studio       | ~35–40% Landing emotion; Mode before Photos; no workspace theme skins                                                                           |

| Themes       | Atmospheres in one family; optional ceremonial font; accentText = contrast + harmony                                                            |
