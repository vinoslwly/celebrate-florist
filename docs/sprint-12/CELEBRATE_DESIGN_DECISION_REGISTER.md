## Purpose

This register is **not** meeting notes. It records every **founder-approved** visual decision during Sprint 12 so future discussions do not reopen settled choices.

Each entry includes: Decision ID · Date · Status · Decision · Reasoning · Impact · Related Sprint Phase.

**Rules:**

- Append new entries; do not delete approved decisions (mark **Superseded** if replaced).
- Implementation changes require a new entry or explicit founder revision.
- Production Pending items are **not** decisions — they belong in the Baseline doc.

### DDR-S12-001 — Sage Palette Role

| Field          | Value                                                                                                                                                                 |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Date**       | 2026-07-19                                                                                                                                                            |
| **Status**     | ✅ **Approved**                                                                                                                                                       |
| **Decision**   | **Keep Sage.** Sage is a **supporting botanical color**, not a primary Celebrate color.                                                                               |
| **Reasoning**  | Supports florist identity without competing with pink/peach/cream emotional core.                                                                                     |
| **Usage**      | Natural accents, leaves, eucalyptus, subtle supporting surfaces, premium botanical sections, success-adjacent accents where appropriate, decorative florist elements. |
| **Constraint** | Sage must **not** compete visually with pink, peach, or cream. Pink remains emotional identity; Sage supports botanical identity.                                     |
| **Impact**     | Design Foundations (Phase 3) — document official sage roles. Do not deprecate sage tokens.                                                                            |
| **Phase**      | 3 — Design Foundations                                                                                                                                                |
