# `public/themes/warm/memories/`

Warm Memories Theme Lab does **not** ship new runtime image plates in this folder.

## Runtime reuse (intentional)

| Need                         | Source                                                                      |
| ---------------------------- | --------------------------------------------------------------------------- |
| Match photo fixtures         | `/themes/bloom/moments/gallery-fixtures/*.webp` (via Warm Moments lab photos) |
| Score / quiz atmosphere      | `/themes/warm/connection/*.webp` (Connection living scenes)                 |
| Ceremony gift / letter art   | Warm Moments / Warm Connection presentation components                      |

Design references live under `design-references/warm/memories/` (not runtime).

Keep this README so asset audits know the empty folder is deliberate reuse, not a missing delivery.
